# 나의 성적

기린국어 학생 계정으로 로그인하면 최근 숙제·시험 점수와 집계 결과를 볼 수 있는 별도 Next.js 앱입니다.

## 실행

Node.js 20.9 이상과 pnpm을 설치합니다. `pnpm install` 후 `.env.example`을 `.env.local`로 복사하고 `GIRIN_SESSION_SECRET`에 임의의 긴 문자열(32자 이상)을 설정합니다. `pnpm dev`를 실행합니다.

## Vercel 배포

이 저장소를 Vercel에 연결하고 환경 변수 `GIRIN_SESSION_SECRET`을 Production, Preview에 각각 설정합니다. 코드에 비밀번호나 이 값을 저장하지 않습니다. `NEXT_PUBLIC_ADSENSE_CLIENT`에 본인의 `ca-pub-...` 값을 넣으면 Google 자동 광고 스크립트가 활성화됩니다. 실제 광고 게재에는 AdSense 사이트 승인과 자동 광고 설정이 필요합니다. 광고가 성적 화면을 가리지 않도록 AdSense에서 위치를 조정하세요.

## 집계 기준

최근 채점된 12건을 표시합니다. 테스트 집계 대상 번호 3034–3322의 같은 숙제·시험 ID와 점수만 집계합니다. `등급컷`은 이 표본의 점수 분포에서 동점자의 중간 순위를 사용해 계산한 추정치이며 공식 등급컷이 아닙니다. 한 명이라도 집계 조회가 실패하면 평균·등수·등급컷을 숨기고 재시도를 안내합니다.

기린국어 API가 학생 목록을 번호로 공개하는 현재 동작에 의존합니다. 기린국어 서버에서 번호 접근을 제한하면 별도의 공식 집계 API나 서버 측 서비스 계정이 필요합니다. 화면과 JSON 응답에는 다른 학생의 이름·번호·개별 점수가 포함되지 않습니다.
